# Security policy

## Reporting a vulnerability

Please don't report security issues in public GitHub issues, discussions or pull requests.

Report them privately instead:

- through [GitHub's private vulnerability reporting](https://github.com/DouweBos/Hermes/security/advisories/new), or
- by email to [douwe@douwebos.nl](mailto:douwe@douwebos.nl).

Include what you found, the steps to reproduce it, the affected Hermes and macOS versions, and the impact you expect. You'll get a reply as soon as possible, and you'll be kept informed while a fix is prepared. Once it's released, you're welcome to be credited in the advisory.

## Supported versions

Hermes is a small project maintained in spare time. Fixes go into the latest release only.
